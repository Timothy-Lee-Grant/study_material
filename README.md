# Studying Lectures

A personal collection of lecture-style documents I generate while building my own projects, so I have a single place to study and learn the concepts more deeply afterward.

This started as a private repo, but I'm making it public in case anyone else finds something useful here too.

## Structure

- `lectures/` — lecture documents, grouped by topic/project area
- `project_ideas/` — notes on project ideas

Not meant to be a polished course — just my personal study notes.
