# OUTLINE ONLY: `learning_style.md`

> **Not real content.** This is the proposed structure for a new global document. See `README.md` in this folder.

**Purpose:** the one global description and analysis of how I learn. It applies to every project, so every project's sessions read it and feed it. This is the document that makes the system better over time.
**Updated by:** the AI. After any session that shows something that would hold in any subject, the evidence goes into the observation log; the document itself is revised at consolidation points (every 3 sessions or monthly).
**Rule for every line:** dated evidence, tagged as observed, self-reported or inferred. Each pattern carries a status: strengthening, unchanged, weakening or resolved.

## Proposed sections

1. **In ten lines.** The portrait a new session needs before teaching anything.
2. **How I build understanding.** Top-down map first; the causal model (where it runs, who calls it); the bottom-up default and what counters it.
3. **How I show what I know, and how to read it.** Walk-and-talk voice transcripts, comments in attempts, written explain-backs. What each one reveals. The table of voice-to-text mishearings would live here.
4. **Explanations that click.** The patterns from the clicks log, each with one example: named quantities and valid sets, what a symbol stands for, numbers before formulas, one canonical procedure, worked walkthroughs, code next to the explanation.
5. **What doesn't work.** Retired techniques and why: firmware analogies, personified characters, several framings at once, series of lectures in place of one document.
6. **Confusion patterns that cross subjects.** Patterns only (mixing layers, an unnamed actor such as "the OS", formulas without a model of their quantities). The subject-level detail stays in project trackers.
7. **Study habits and their effects.** Generated versus learned; number of open threads; learn-and-forget revisits; what gets done on weekdays versus weekends.
8. **Calibration.** How often flagged doubts turn out to be justified, and how to use that.
9. **Teaching rules that follow from the above.** The single home for "how to teach me". `lecture_standards.md`, `where_i_stand.md` and project charters link here instead of repeating it.
10. **Hypotheses under test.** Techniques being tried, with the evidence so far.
11. **Changelog.** Dated: what changed and on what evidence.
