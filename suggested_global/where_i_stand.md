# OUTLINE ONLY: `where_i_stand.md`

> **Not real content.** This is the proposed structure for `where_i_stand.md`. See `README.md` in this folder.

**Purpose:** the cross-project status page: what I'm good at, where each project stands against its bar, and what I'm working on. A rollup. The detail lives in each project's tracker and `000-` docs, and this file links to them.
**Target length:** about half the current file.
**Updated by:** the AI, when a project's status changes or a strength shows up. Rows are rewritten in place; history goes in the changelog.

## Proposed sections

0. **Hand-off summary.** The paste-able block for other projects and AI sessions, 25 lines at most. Kept as it is today.
1. **Snapshot.** Five lines: what's true this month.
2. **Strengths, with evidence.** Kept as it is today.
3. **Projects.** One row per learning project: project | goal | status against its bar | last evidence (date) | next step | link to its `000-next_steps.md`. This replaces the long gap tables.
4. **Growth areas that cross projects.** Only the ones no single project owns (retention, answering at the altitude of the question, too many open threads).
5. **Not in a project yet.** Areas that are parked or not started, one line each.
6. **Numbers.** The few counts worth tracking month over month.
7. **Keeping this file current.** Which event updates which section, and which project files feed it.
8. **Changelog.**
