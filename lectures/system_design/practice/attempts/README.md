# Attempts

One folder per attempt, created by `python3 ../practice.py start <id>`:

```
attempts/
  2026-11-07_a01_url_shortener/
    attempt.md        ← your notes for each step + self-review (created from the template)
    timer_log.txt     ← when you entered each phase (written by the timer)
    diagram.jpg       ← a photo of your paper diagram, or an Excalidraw export (add it yourself)
    review.md         ← written by Claude when you ask for a review
```

A second attempt at the same case on the same day gets `_2` at the end.

**What to write in `attempt.md`:** short notes under each step are enough; it's a record, not an essay. The thinking happens out loud. What matters most is the **self-review** at the bottom, filled in before you open the case's hidden notes.

**Asking for a review:** "review my system design attempt `attempts/<folder>`." If you used interviewer mode, paste the interviewer's summary into `attempt.md` first.
